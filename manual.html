Manual Técnico del Sitio Web Personal

1. Requisitos Previos

  • Editor de código: Visual Studio Code
  • Navegador web: Google Chrome
  • Conocimientos en HTML5, CSS3 y conceptos básicos de JavaScript

2. Estructura del Proyecto

/Pagina web personal/
│
├── index.html              (Inicio)
├── vida.html               (Hoja de vida)
├── galeria.html            (Galería)
├── juego.html              (Juego interactivo)
├── notas.html              (Notas académicas)
├── video.html              (Video de presentación)
├── manual.html             (Este documento)
│
├── /css/                   (varios .css como galeria.css, nav.css, etc.)
├── /img/                   (Imágenes y recursos visuales)
├── script.js               (Funciones JS generales)
├── palabras.js             (JS adicional para el juego)

3. Desarrollo del Sitio

  • Se definió un diseño básico para cada página usando HTML.
  • Se aplicaron estilos con archivos CSS individuales según el módulo (por ejemplo: galeria.css, vida.css).
  • Se incorporaron imágenes y multimedia en la carpeta /img.
  • Se usó JavaScript para interacciones como el juego y efectos visuales.

4. Pruebas y Validación

  • Verificación de enlaces internos y navegación.
  • Revisión visual en diferentes navegadores.
  • Validación de formularios y carga de contenido multimedia.

5. Publicación y Uso

  • Para visualizar el sitio basta con abrir index.html en un navegador.
  • Puede subirse a GitHub Pages o Netlify para mostrarlo en línea.

6. Mantenimiento

  • Los archivos son editables con cualquier editor de texto.
  • Para actualizar contenido, modificar directamente los archivos HTML, CSS o JS según corresponda.
